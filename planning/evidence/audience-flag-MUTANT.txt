MUTANT 2 -- one stripper removed
----------------------------------
    const withoutTitle = markdown.replace(/^#\s+.*\r?\n/, '');   // <- stripFrontmatter dropped

$ npx vitest run apps/field-manual/tests/published.test.ts

     x prints no frontmatter on any page of either site
       AssertionError: area-0.html prints its frontmatter:
         expected '<!doctype html>...' not to match /audience:\s*(learner|dm)/i
       Tests  1 failed | 12 passed (13)

Three strippers have to run for no metadata to reach a page -- `briefBody` for lessons and
briefs, `howToUnder` for the how-to sections, and the API's `read` for the SPA. Removing one is
enough to fail, which is what makes the assertion worth having.

The failure is also the ugly one rather than a cosmetic one: `marked` renders a leading `---`
block as a heading and a horizontal rule, so the page gains a stray title AND prints the word
`dm` to a learner -- on the page the block exists to keep from them.
