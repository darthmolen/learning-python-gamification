# Area 1 glossary

Area 1 teaches ten concepts. This file defines two of them, misspells a third, and invents a
fourth — one fixture holding both halves of the rule.

## if

Runs the block underneath only when the condition is true.

## elif

Otherwise, try this question instead.

## whlie

A typo of `while`. The registry has never heard of it, which is the mistake the rule exists to
catch before it reaches a chip nobody can click.

## dict

A real concept, and Area 3's rather than this one's. Defining it here would put it on the wrong
page.
