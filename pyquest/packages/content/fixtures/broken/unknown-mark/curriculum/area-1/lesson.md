# Control

A lesson that marks three words. Two of them are real concepts and one is not, which is the
whole point of this fixture.

The [[if]] statement runs a block when a condition holds, and [[whlie|the loop]] repeats it —
that second id is a typo an author would make and a reader would never see, because the mark
would simply resolve to nothing.

A [[range]] is a span of numbers.

The syntax itself has to be documentable, so neither of these counts:

```markdown
[[not-a-concept]]
```

An inline `[[also-not-a-concept]]` is the other way a lesson names the syntax without using it.
