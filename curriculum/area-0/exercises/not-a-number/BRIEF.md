# Not A Number

You met this one in session 3. The order is spelled right, the brackets are closed, the
indentation is fine, and it still falls over.

`int()` turns text into a number. Usually.

This error is about a **value**, not a name and not a kind of thing. Python was perfectly
willing to look at what it was given. It just could not read it.

## What to do

1. **Run it.** Write down the error's name and its line number.
2. **Say what `int()` would have accepted instead.** The word `ten` is a number to you. Why
   is it not one to Python?
3. **Fix it so the turtle walks ten steps.**

## The rule that matters

**Fix the line. Do not delete it** — and do not delete the order underneath it either. The
size has to be ten, and the turtle has to be told to move.

## Done when

It runs without complaint and the turtle walks ten steps.
