# The Perimeter

You drew this rectangle in session 2, and it is still written the way session 2 warned you
about: the size is typed into four separate orders. Change it and you have to find every
one. Miss one and the shape does not close.

## What to do

1. **Give the height a name**, set once at the top.
2. **Make the width exactly twice the height** — and make it stay twice the height when the
   height changes. There should be exactly **one** number you can edit.
3. **Draw the rectangle using those names**, not typed numbers.
4. **Print the perimeter**, on its own line, in this exact shape:

   ```text
   perimeter: 360
   ```

## The rule that matters

**Compute the perimeter. Do not type it.**

Somebody is going to change your height to 50 and run it again. The printed number has to
change with it, and so does the rectangle. That is the whole quest — everything else is
scaffolding for it.

## Done when

Your program draws a rectangle twice as wide as it is tall, prints its perimeter, and both
of those follow when the one editable number changes.
