# The entries moved into `journal.md`

There are no entry files any more, and this directory is kept only to say so.

**Everything goes in one `journal.md`**, at the top level of his own folder — later, of his
own repository. One entry per session, newest at the bottom, each one starting with a dated
heading copied from `../TEMPLATE.md`:

```markdown
## 2026-08-31 — Session 01
```

**Ruled 2026-08-31.** The earlier layout was one file per session in here — `session-01.md`,
`session-02.md` and so on — and it was changed for the learner rather than for the code. "Which
file do I write in tonight?" now has one answer, the same every week, and there is no numbering
to keep track of and no file to name.

The date on that heading is not decoration. It is what the game reads to tell one entry from the
next, and it is the same date the ledger pays against — so `2026-08-31`, never `Aug 31`. It is in
the template to be copied for exactly that reason.

This directory goes the next time somebody is editing Area 0 for another reason. It is left for
now because a note saying where the entries went is worth more than a clean tree to anybody who
followed a link here.
