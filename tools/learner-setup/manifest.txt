# The payload: what gets carried onto a learner's machine.
#
# One repository-relative path per line. Directories are copied whole. `#` comments
# and blank lines are ignored. `pack.sh` reads this file and nothing else decides
# what ships, so adding a file here is the entire change.
#
# The rule for what belongs: a learner's machine needs the instructions for the
# installs, and the files those installs are verified against. It does not need the
# application, the host, the API, the SPA, or the content pipeline -- those live on
# the DM's machine (spec 6.1) and shipping them would invite somebody to run them in
# the wrong place.
