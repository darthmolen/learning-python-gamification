# The Typo

Broken sigil 1, from session 3. It is broken on purpose, and the fix is one character.

That is not what this quest is for. It is for the thing Python says on the way down, which
you will read several hundred more times before this campaign is over: an error has a
**name** and a **line number**, and those two together tell you almost everything.

## What to do

1. **Run it before you change anything.** Read the error out loud.
2. **Write down its name and its line number.** Not roughly — exactly.
3. **Fix the line.**

## The rule that matters

**Fix the line. Do not delete it.**

Deleting it makes the error go away, and it makes the drawing go away too — what is left is
one long straight line instead of a corner. Silencing an error is not the same as fixing it,
and this quest can tell the difference.

## Done when

It runs without complaint, and the turtle still walks a hundred steps, turns its corner, and
walks a hundred more.
